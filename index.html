    7. SW Setwork snelstartgids

    ⚙️ Zaagverlies instellen
    1. Houd KERF ingedrukt.
    2. Voer de werkelijke zaagsnedebreedte in.
    3. Opslaan met NEXT CUT.
    📏 Werkelijke bandhoogte instellen
    1. Meet de werkelijke hoogte tussen band en zaagbed.
    2. Houd SET HEIGHT ingedrukt.
    3. Voer de juiste gemeten hoogte in.
    4. Opslaan met NEXT CUT.
    ⚙️ Zaagtype LT20/40

    Controleer de originele snelstartkaart.

    1. Schakel SW10 in.
    2. Houd CALIBR. ingedrukt wanneer SW10 oplicht.
    3. Instelwaarde LT20/40 volgens de kaart: 5.
    4. Opslaan met NEXT CUT.

    Controleer of deze waarde bij jouw machine en besturingsversie hoort.

    ⚙️ Automatische kalibratie
    1. Breng de band volgens de snelstartkaart op 150 mm hoogte.
    2. Houd CALIBR. ingedrukt tot Auto Cal verschijnt.
    3. Druk opnieuw op CALIBR.
    4. Wacht op End Cal.
    5. Vergelijk de werkelijke bandhoogte met het display.

    Volg de veiligheidsvoorwaarden uit de machinehandleiding.

    🟩 Normale modus
    1. Voer de gewenste maat in of selecteer A, B of C.
    2. Selecteer NEXT CUT.
    3. Controleer de positie voor het zagen.
    ⬇️ QUICK PROGRAM
    1. Positioneer de band op de stam.
    2. Voer de gewenste dikte in.
    3. Selecteer QUICK PROGRAM.
    4. Pas indien nodig de dikte aan met de pijltjestoetsen.
    5. Selecteer NEXT CUT voor de startpositie.
    6. Opslaan met SAVE PROGRAM volgens de kaart.
    ⬆️ MANUAL PROGRAM
    1. Positioneer de band op de stam.
    2. Druk op MANUAL PROGRAM.
    3. P-1 verschijnt.
    4. Voer de onderste plaatdikte in.
    5. Druk op de pijl omhoog.
    6. Voer de volgende dikte in.
    7. Herhaal voor de overige diktes.
    8. Selecteer NEXT CUT voor de startpositie.
    9. Opslaan met SAVE PROGRAM volgens de kaart.
    🟩 Nieuw A B C programma opslaan
    1. Houd een programmatoets ingedrukt.
    2. Gebruik DEL. PRG. / EXIT alleen als je het bestaande programma wilt wissen.
    3. Houd de gewenste programmatoets ingedrukt.
    4. Voer de onderste plaatdikte in.
    5. Gebruik MANUAL PROGRAM voor de volgende diktes.
    6. Opslaan met SAVE PROGRAM.
    🟩 Werken met A B C programma's
    1. Houd de gewenste programmatoets ingedrukt.
    2. Gebruik de pijltjestoetsen voor de eerste startpositie.
    3. Voer eventueel een andere maat in.
    4. Selecteer NEXT CUT.
    5. Opslaan met SAVE PROGRAM volgens de kaart.
    🟩 A B C vaste waarden opslaan
    1. Schakel SW10 in.
    2. Houd A, B of C ingedrukt wanneer SW10 oplicht.
    3. Druk opnieuw op dezelfde programmatoets.
    4. Voer de maat in.
    5. Opslaan met NEXT CUT.
    🟨 BUMP UP High en Low
    1. Schakel SW10 in.
    2. Houd BUMP UP ingedrukt wanneer SW10 oplicht.
    3. Selecteer Hi of Lo met de pijltjestoetsen.
    4. Stel de benodigde afstand in volgens de originele kaart.
    5. Opslaan met NEXT CUT.
    ⬆️ Vaste retourhoogte
    1. Breng de zaagkop op de gewenste retourhoogte.
    2. Druk op SAVE PROGRAM tot het lampje brandt.

    Controleer voldoende vrije ruimte en volg de originele instructies.

    De bedieningsuitleg is een hulpmiddel. Controleer de toetsvolgorde en instellingen aan de hand van de originele Wood-Mizer handleiding. De app bestuurt de machine niet rechtstreeks.
