Wood-Mizer LT20 Start

🪵

Hoe wil je werken?

Stap voor stap met plaatjes en gesproken uitleg.

Alle technische gegevens en instellingen.

📏

1. Meet de boom

Meet de kleinste diameter zonder schors.

📷

2. Voorkant van de boom

Maak een foto. Zet groene punten rondom de rand van het hout.

📷

3. Achterkant van de boom

Maak een foto van de andere kant. Zet weer groene punten.

Laat de richting van beide foto's controleren.

4. Welk hout wil je maken?

🟩 Balken

🟨 Planken

5. Jouw hout

🟩 Groen = balken

🟨 Geel = planken

🔴 Rode lijnen = horizontale zaagzones.

🔵 Blauwe lijnen = breedtebewerking.

🔄

6. Hoe gaan we zagen?

Laat je begeleider bepalen of draaien nodig en veilig is.

Voorgestelde lagen

    Referentiehoogtes zijn geen gevalideerde machineposities.

    👷 Laat de ligging, opspanning en zaagvolgorde controleren.

    ⚙️

    7. Machine instellen

    KERF Zaagverlies controleren.
    SET HEIGHT Zaaghoogte controleren.
    NEXT CUT Volgende zaagpositie.
    BUMP UP Zaagkop omhoog. Controleer de vrije ruimte.
    A B C Opgeslagen programma's.
    ↑ MANUAL PROGRAM Verschillende laagdiktes.
    QUICK PROGRAM ↓ Gelijke laagdiktes.
    SAVE PROGRAM Programma opslaan.
    DEL. PRG. EXIT Programma verwijderen of verlaten.
    CALIBR. Kalibratie volgens de handleiding.

    Voorgestelde instellingen

    Gebruik de originele Wood-Mizer handleiding. De app bestuurt de machine niet.

    ✅

    8. Samen controleren

    Begin alleen volgens de veiligheidsafspraken op je werkplek.
