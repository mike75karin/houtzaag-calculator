    7. Originele SW Setwork snelstartgids

    🔴 KERF — zaagverlies
    1. Houd KERF ingedrukt.
    2. Voer de werkelijke zaagsnedebreedte in.
    3. Opslaan met NEXT CUT.
    🔵 SET HEIGHT — bandhoogte
    1. Meet de werkelijke bandhoogte boven het zaagbed.
    2. Houd SET HEIGHT ingedrukt.
    3. Voer de juiste hoogte in.
    4. Opslaan met NEXT CUT.
    🔴 CALIBR. — zaagtype

    Volgens de aangeleverde snelstartkaart:

    1. Schakel SW10 in.
    2. Houd CALIBR. ingedrukt wanneer SW10 oplicht.
    3. LT15: waarde 20. LT20/40: waarde 5.
    4. Opslaan met NEXT CUT.

    Controleer de machine- en besturingsversie.

    🔴 Automatische kalibratie
    1. Volgens de kaart: bandhoogte 150 mm.
    2. Houd CALIBR. ingedrukt tot Auto Call verschijnt.
    3. Druk opnieuw op CALIBR.
    4. Wacht op End-Call.
    5. Vergelijk de werkelijke hoogte met het display.

    Volg hierbij alle veiligheidsvoorwaarden uit de handleiding.

    🟢 Normale modus
    1. Gewenste maat invoeren of A, B of C kiezen.
    2. NEXT CUT selecteren.
    3. Controleer de positie voordat je zaagt.
    🔵 QUICK PROGRAM — gelijke diktes
    1. Positioneer de band op de stam.
    2. Voer de gewenste afmeting in.
    3. Selecteer QUICK PROGRAM.
    4. Pas eventueel de dikte aan met de pijltjestoetsen.
    5. NEXT CUT voor de startpositie.
    6. SAVE PROGRAM volgens de originele kaart.
    🔵 MANUAL PROGRAM — verschillende diktes
    1. Positioneer de band op de stam.
    2. Selecteer MANUAL PROGRAM. P-1 verschijnt.
    3. Voer de onderste plaatdikte in.
    4. Druk op de pijl omhoog.
    5. Voer de volgende plaatdikte in en herhaal.
    6. NEXT CUT voor de startpositie.
    7. SAVE PROGRAM volgens de originele kaart.
    🟢 Nieuw A B C programma
    1. Houd de programmatoets ingedrukt.
    2. Gebruik DEL. PRG. alleen wanneer je bestaande instellingen wilt wissen.
    3. Selecteer de gewenste programmatoets.
    4. Voer de onderste plaatdikte in.
    5. Gebruik MANUAL PROGRAM voor volgende diktes.
    6. SAVE PROGRAM.
    🟢 Werken met A B C programma's
    1. Houd de gewenste programmatoets ingedrukt.
    2. Selecteer de startpositie met de pijltjestoetsen.
    3. Voer eventueel een andere maat in.
    4. NEXT CUT.
    5. SAVE PROGRAM volgens de kaart.
    🟢 A B C vaste waarden opslaan
    1. Schakel SW10 in.
    2. Houd A, B of C ingedrukt wanneer SW10 oplicht.
    3. Druk opnieuw op dezelfde toets.
    4. Voer de maat in.
    5. NEXT CUT om op te slaan.
    🟨 BUMP UP High en Low
    1. Schakel SW10 in.
    2. Houd BUMP UP ingedrukt wanneer SW10 oplicht.
    3. Selecteer Hi of Lo met de pijltjestoetsen.
    4. Stel de afstand in volgens de originele kaart.
    5. Opslaan met NEXT CUT.
    🔵 Vaste retourhoogte
    1. Breng de zaagkop op de gewenste retourhoogte.
    2. Druk op SAVE PROGRAM tot het lampje brandt.

    Controleer voldoende vrije ruimte.

    Deze gids is gebaseerd op de twee aangeleverde Wood-Mizer snelstartkaarten. De app bestuurt de machine niet. De originele handleiding blijft leidend.
